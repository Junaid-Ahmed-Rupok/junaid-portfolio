## 👤 About Me

> *"Advancing methodological rigor at the intersection of machine learning and governance analytics."*

I am **Sarder Junaid Ahmed**, a BSc graduate in Computer Science & Engineering from **RUET** (February 2025) and a PhD applicant in Computational Science. My research develops statistically valid frameworks for computational social science, fairness-aware machine learning, and causal inference in observational studies.

I believe good research is not just about results — it's about **rigour, reproducibility, and honest uncertainty quantification**.

## 🔬 Featured Projects

### 📌 [BD Crime Analysis](https://github.com/Junaid-Ahmed-Rupok/BD_Crime_Analysis)
> **Machine Learning · Ethics · Fairness**

Ensemble system achieving **94.1% accuracy** on 6-class crime prediction using XGBoost. Includes fairness analysis revealing demographic parity gaps and the need for human oversight. Addresses class imbalance with principled resampling strategies.

### 📌 [Economic Status Classification](https://github.com/Junaid-Ahmed-Rupok/economic_status)
> **Economics · Deep Learning · World Bank Data**

ML system classifying 150+ countries as developed/developing using World Bank indicators. Achieves **98.3% accuracy** through principled high-dimensional feature selection with robust cross-validation and generalisation testing.

### 📌 [Annual Enterprise Survey EDA](https://github.com/Junaid-Ahmed-Rupok/_Annual_EnterPriese_survey_by_Junaid_Rupok)
> **Data Analysis · Statistical Testing · Visualization**

Rigorous exploratory data analysis on New Zealand enterprise survey data — **55,620 records** across **117 industries**. One-Way ANOVA testing with p < 0.001. Professional visualisations and a reproducible data pipeline.
